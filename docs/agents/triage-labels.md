# Labels

This file maps the terms in the skills to the label strings in this repo's tracker.

When a skill gives a role (for example, "apply the AFK-ready triage label"), use the applicable label from these tables.

To use different labels, edit the "Label in our tracker" column.

## Triage labels

| Label in mattpocock/skills | Label in our tracker | Meaning                                       |
| -------------------------- | -------------------- | --------------------------------------------- |
| `needs-triage`             | `needs-triage`       | A maintainer must evaluate this issue.        |
| `needs-info`               | `needs-info`         | The reporter must give more information.      |
| `ready-for-agent`          | `ready-for-agent`    | This issue is fully specified for an AFK agent. |
| `ready-for-human`          | `ready-for-human`    | A human must do this work.                    |
| `wontfix`                  | `wontfix`            | No person will do this work.                  |

## Wayfinder labels

| Label in mattpocock/skills | Label in our tracker  | Meaning                    |
| -------------------------- | --------------------- | -------------------------- |
| `wayfinder:map`            | `wayfinder:map`       | This issue is a map.       |
| `wayfinder:research`       | `wayfinder:research`  | This ticket is research.   |
| `wayfinder:prototype`      | `wayfinder:prototype` | This ticket is a prototype. |
| `wayfinder:grilling`       | `wayfinder:grilling`  | This ticket is a grilling session. |
| `wayfinder:task`           | `wayfinder:task`      | This ticket is a task.     |
